# Slice 11 (simplified): Source text extractor, `.docx`

An alternative to [`phase-37-11.md`](./phase-37-11.md). Build **one** of the two. Same goal (SC-3 docx, SC-5, SC-7 of [`phase-37.md`](./phase-37.md)), with the least code that still validates the file. **Nothing calls the extractor yet**: the controller and `GenerateFormHandler` don't change until slice 13.

## What changed from `phase-37-11.md`

| Before | Now |
|---|---|
| `LimitedReadStream` counting bytes while streaming | **Removed.** `XmlReaderSettings.MaxCharactersInDocument` makes the XML parser count what it actually parses and throw past the limit. It is the same protection (the numbers come from the content, not the headers), with no custom class. |
| `ZipLimits` public class | **Removed.** Two private constants in the extractor. Move them out when slice 12 needs them. |
| Hand-written `XmlReader` loop with a state flag | `XDocument` plus one LINQ query. |
| Tabs, line breaks and table cells handled one by one | Same behavior for tabs and breaks in a `switch` expression; table cells are paragraphs, so they need nothing. |
| 18 tests | 12, one per rule. |

## Decisions

| Topic | Decision |
|---|---|
| Dependencies | None new (`System.IO.Compression`, `System.Xml.Linq`). |
| Is it really a docx | No PK / magic-byte check. `ZipArchive` throws on a non-zip file, and a zip without `word/document.xml` is rejected. Both answer `SourceFileUnreadable`. |
| Entry count | More than 1,000 entries is rejected, checked right after opening. |
| Decompressed size | `MaxCharactersInDocument = 20,000,000` on the XML reader. The parser counts the characters it reads and throws `XmlException`, so a zip bomb (a tiny file that expands to gigabytes) stops at the limit. Header sizes are never used. 20 M is far above any real document, and the combined text is cut to 30,000 characters in slice 13 anyway. |
| XML | `DtdProcessing.Prohibit` and no resolver (DTD / XXE off). |
| Extracted | `w:t` text per `w:p` paragraph (one line each), tab as `\t`, `w:br` as `\n`. Tables come out as one line per cell paragraph. |
| Ignored | Headers, footers, footnotes, comments, images, charts, field codes, tracked-deletion text. |
| Cleaning | Trim only, reject an empty result (as in slice 10). XML 1.0 already forbids NUL and most control characters, so they end as `SourceFileUnreadable`. |
| Errors | `ValidationException` with the slice 10 codes (400). Fixed messages, no file name or content. |
| Known limits | Text boxes can appear twice or not at all (Word stores them in nested paragraphs and a fallback copy). Password-protected docx is not a zip and answers `SourceFileUnreadable`. Old `.doc` stays unsupported. |

## 1. Code

### 1.1 New `src/FormAI.Infrastructure/Files/DocxTextExtractor.cs`

```csharp
using System.IO.Compression;
using System.Xml;
using System.Xml.Linq;

namespace FormAI.Infrastructure.Files;

internal static class DocxTextExtractor
{
    // A real docx has tens of entries, a few hundred with many images.
    private const int MaxEntries = 1000;

    // Counted by the XML parser while it reads, so it can't be faked by a header.
    private const long MaxXmlCharacters = 20_000_000;

    private static readonly XNamespace W = "http://schemas.openxmlformats.org/wordprocessingml/2006/main";

    public static string Extract(byte[] content)
    {
        try
        {
            using var archive = new ZipArchive(new MemoryStream(content), ZipArchiveMode.Read);

            if (archive.Entries.Count > MaxEntries)
                throw SourceTextExtractor.Unreadable();

            // Also rejects a pptx, an xlsx or a plain zip renamed to .docx.
            var entry = archive.GetEntry("word/document.xml") ?? throw SourceTextExtractor.Unreadable();

            using var xml = XmlReader.Create(entry.Open(), new XmlReaderSettings
            {
                DtdProcessing = DtdProcessing.Prohibit,
                XmlResolver = null,
                MaxCharactersInDocument = MaxXmlCharacters
            });

            var paragraphs = XDocument.Load(xml).Descendants(W + "p").Select(ParagraphText);
            var text = string.Join("\n", paragraphs).Trim();

            // Also covers a document with only images.
            return text.Length > 0 ? text : throw SourceTextExtractor.Unreadable();
        }
        // Not a zip, a corrupt zip, or XML that is malformed, has a DTD or is over the limit.
        catch (Exception ex) when (ex is InvalidDataException or XmlException)
        {
            throw SourceTextExtractor.Unreadable();
        }
    }

    private static string ParagraphText(XElement paragraph) =>
        string.Concat(paragraph.Descendants().Select(e => e.Name.LocalName switch
        {
            "t" => e.Value,
            "tab" => "\t",
            "br" => "\n",
            _ => ""
        }));
}
```

### 2.2 New `tests/FormAI.UnitTests/Files/DocxTextExtractorTests.cs`

```csharp
using System.IO.Compression;
using System.Text;
using FormAI.Application.Common.Exceptions;
using FormAI.Domain.Entities;
using FormAI.Infrastructure.Files;

namespace FormAI.UnitTests.Files;

public class DocxTextExtractorTests
{
    private const string W = "http://schemas.openxmlformats.org/wordprocessingml/2006/main";

    private readonly SourceTextExtractor _extractor = new();

    // ---- helpers ----

    private static string Document(string body) =>
        $"<w:document xmlns:w=\"{W}\"><w:body>{body}</w:body></w:document>";

    private static string Para(string text) => $"<w:p><w:r><w:t>{text}</w:t></w:r></w:p>";

    private static byte[] Zip(params (string Name, string Content)[] files) =>
        Zip(zip =>
        {
            foreach (var (name, content) in files)
            {
                using var writer = new StreamWriter(zip.CreateEntry(name).Open(), new UTF8Encoding(false));
                writer.Write(content);
            }
        });

    private static byte[] Zip(Action<ZipArchive> fill)
    {
        var buffer = new MemoryStream();
        using (var zip = new ZipArchive(buffer, ZipArchiveMode.Create, leaveOpen: true))
            fill(zip);
        return buffer.ToArray();
    }

    private static byte[] Docx(string documentXml) => Zip(("word/document.xml", documentXml));

    private ValidationErrorCode? CodeOf(string fileName, byte[] content) =>
        Assert.Throws<ValidationException>(() => _extractor.Extract(fileName, content)).Code;

    // ---- extraction ----

    [Fact]
    public void Extract_ReturnsOneLinePerParagraph_JoiningTheRuns()
    {
        var body = "<w:p><w:r><w:t>Hel</w:t></w:r><w:r><w:t>lo</w:t></w:r></w:p>" + Para("World");

        Assert.Equal("Hello\nWorld", _extractor.Extract("notes.docx", Docx(Document(body))));
    }

    [Fact]
    public void Extract_ReadsTabsAndLineBreaks()
    {
        var body = "<w:p><w:r><w:t>a</w:t><w:tab/><w:t>b</w:t><w:br/><w:t>c</w:t></w:r></w:p>";

        Assert.Equal("a\tb\nc", _extractor.Extract("notes.docx", Docx(Document(body))));
    }

    [Fact]
    public void Extract_ReadsTableCellsAsLines()
    {
        var body = $"<w:tbl><w:tr><w:tc>{Para("A")}</w:tc><w:tc>{Para("B")}</w:tc></w:tr></w:tbl>";

        Assert.Equal("A\nB", _extractor.Extract("notes.docx", Docx(Document(body))));
    }

    [Fact]
    public void Extract_KeepsSpecialCharactersAndTrims()
    {
        var body = "<w:p/>" + Para("Educação &amp; saúde") + "<w:p/>";

        Assert.Equal("Educação & saúde", _extractor.Extract("NOTES.DOCX", Docx(Document(body))));
    }

    [Fact]
    public void Extract_IgnoresTrackedDeletionsAndFieldCodes()
    {
        var body = "<w:p><w:r><w:t>kept</w:t></w:r><w:del><w:r><w:delText>gone</w:delText></w:r></w:del>" +
                   "<w:r><w:instrText>PAGE</w:instrText></w:r></w:p>";

        Assert.Equal("kept", _extractor.Extract("notes.docx", Docx(Document(body))));
    }

    // ---- rejections ----

    [Fact]
    public void Extract_Throws_SourceFileUnreadable_WhenTheFileIsNotAZip()
    {
        Assert.Equal(ValidationErrorCode.SourceFileUnreadable,
            CodeOf("fake.docx", Encoding.UTF8.GetBytes("just some text")));
    }

    [Fact]
    public void Extract_Throws_SourceFileUnreadable_WhenThereIsNoWordDocumentEntry()
    {
        // What a pptx renamed to .docx looks like.
        Assert.Equal(ValidationErrorCode.SourceFileUnreadable,
            CodeOf("deck.docx", Zip(("ppt/presentation.xml", "<p/>"))));
    }

    [Theory]
    [InlineData("<w:document")]                                                        // malformed
    [InlineData("<w:document xmlns:w=\"" + W + "\"><w:body><w:p/><w:p/></w:body></w:document>")] // no text
    public void Extract_Throws_SourceFileUnreadable_WhenTheXmlIsBadOrHasNoText(string xml)
    {
        Assert.Equal(ValidationErrorCode.SourceFileUnreadable, CodeOf("bad.docx", Docx(xml)));
    }

    [Fact]
    public void Extract_Throws_SourceFileUnreadable_WhenTheXmlHasADtd()
    {
        var xml = "<?xml version=\"1.0\"?><!DOCTYPE d [<!ENTITY x \"boom\">]>" + Document(Para("&x;"));

        Assert.Equal(ValidationErrorCode.SourceFileUnreadable, CodeOf("xxe.docx", Docx(xml)));
    }

    [Fact]
    public void Extract_Throws_SourceFileUnreadable_WhenThereAreTooManyEntries()
    {
        var bytes = Zip(zip =>
        {
            zip.CreateEntry("word/document.xml");
            for (var i = 0; i < 1000; i++)
                zip.CreateEntry($"word/media/image{i}.png");
        });

        Assert.Equal(ValidationErrorCode.SourceFileUnreadable, CodeOf("many.docx", bytes));
    }

    [Fact]
    public void Extract_Throws_SourceFileUnreadable_WhenTheXmlExpandsPastTheLimit()
    {
        // A few tens of KB zipped, over 20 million characters once decompressed.
        var bytes = Zip(zip =>
        {
            using var stream = zip.CreateEntry("word/document.xml").Open();
            var head = Encoding.UTF8.GetBytes($"<w:document xmlns:w=\"{W}\"><w:body><w:p><w:r><w:t>");
            stream.Write(head);

            var chunk = new byte[1024 * 1024];
            Array.Fill(chunk, (byte)'a');
            for (var i = 0; i < 21; i++)
                stream.Write(chunk);
        });

        Assert.True(bytes.Length < FormSourceContent.MaxFileBytes);
        Assert.Equal(ValidationErrorCode.SourceFileUnreadable, CodeOf("bomb.docx", bytes));
    }

    [Fact]
    public void Extract_Throws_SourceFileTooLarge_WhenTheFileIsOverTenMegabytes()
    {
        Assert.Equal(ValidationErrorCode.SourceFileTooLarge,
            CodeOf("big.docx", new byte[FormSourceContent.MaxFileBytes + 1]));
    }
}
```

The "too many entries" test needs 1,001 entries (the document plus 1,000 others). The bomb test writes 21 chunks of 1 MiB (about 22 million characters), which is over the 20 million limit.

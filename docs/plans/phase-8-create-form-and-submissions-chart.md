# Phase 8: "Create new form" button + submissions-per-form chart

## Context

Phase 7 gave users a "My Forms" list on `/dashboard`, but there's still no way to
start a new form from the UI — forms can only be generated by calling the API
directly. Separately, the user wants the first general dashboard chart: a bar
chart of submissions per form, so they can see their most/least answered forms
at a glance.

Good news on both fronts:
- **Create form**: the backend already has a working generation endpoint,
  `POST /api/forms/generate/text` (`GenerateFormHandler`, wired in
  `FormsController.GenerateFromText`). It takes pasted text + a few generation
  parameters and returns the created form's id. No backend work needed — this is
  a frontend-only page + button.
- **Submissions chart**: `GetFormSummaryResponse` (used by the `/dashboard` list)
  doesn't currently include a submission count, so a small backend change is
  needed to add it. Once it's on the DTO, the chart can reuse the exact same
  `listForms()` call the dashboard already makes — no new endpoint or extra
  network request required.

No new npm dependency is added for the chart (no chart library is installed —
`package.json` only has `axios`, `react-hook-form`, `zod`, `react-router-dom`,
`@dnd-kit/*`). Per the project's "keep it simple" direction, this is built as a
small hand-rolled horizontal bar chart using existing Tailwind/`brand-*` classes,
following single-series magnitude-chart conventions: one hue for all bars
(color isn't encoding a second dimension here), thin rounded bars, direct value
labels instead of a legend, sorted descending so "most" and "least" are both
visible at a glance.

## Part A — "Create new form" button

### A1. `frontend/src/api/forms.ts` — add `generateForm()`

Add alongside the existing `getForm`/`updateQuestions`/(phase 7's) `listForms`:

```ts
export interface GenerateFormPayload {
    sourceText: string;
    questionCount: number;
    difficultyLevel: string;
    includeCorrectAnswers: boolean;
}

export interface GenerateFormResult {
    formId: string;
    title: string;
}

export async function generateForm(payload: GenerateFormPayload): Promise<GenerateFormResult> {
    const response = await api.post<GenerateFormResult>('/forms/generate/text', {
        sourceText: payload.sourceText,
        sourceType: 'Text',
        sourceUrl: null,
        questionCount: payload.questionCount,
        allowedTypes: null,
        difficultyLevel: payload.difficultyLevel,
        includeCorrectAnswers: payload.includeCorrectAnswers,
    });
    return response.data;
}
```

Notes:
- The backend's `GenerateFormRequest` record is `(SourceText, SourceType, SourceUrl, QuestionCount, AllowedTypes, DifficultyLevel, IncludeCorrectAnswers)`. We hardcode `sourceType: 'Text'` and `sourceUrl: null` since this page only supports pasted text (matches `GenerateFormHandler`, which today only branches on text anyway). `allowedTypes: null` lets the AI choose from all question types — no need to build type-selection UI for a first version.
- Enums serialize as strings on this API (`Program.cs` registers `JsonStringEnumConverter`), so `'Text'` matches the C# `SourceType.Text` value directly — no numeric mapping needed.
- Response fields are camelCase (`formId`, `title`, …) because ASP.NET Core's default JSON policy is camelCase, matching every other DTO already consumed on the frontend (`FormDetail`, `FormSummary`).

### A2. New `frontend/src/pages/CreateFormPage.tsx`

```tsx
import { useState } from "react";
import { useNavigate, Link } from "react-router-dom";
import { useForm } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";
import z from "zod";
import { generateForm } from "../api/forms";
import { Button } from "../components/Button";
import type { CustomResponse } from "../types/CustomResponse";

const createFormSchema = z.object({
  sourceText: z.string().min(50, "Paste at least 50 characters of source content"),
  questionCount: z.coerce.number().int().min(1, "At least 1 question").max(20, "At most 20 questions"),
  difficultyLevel: z.enum(['Easy', 'Medium', 'Hard']),
  includeCorrectAnswers: z.boolean(),
});

type CreateFormData = z.infer<typeof createFormSchema>;

export function CreateFormPage() {
  const navigate = useNavigate();
  const [serverError, setServerError] = useState<string | null>(null);

  const {
    register,
    handleSubmit,
    formState: { errors, isSubmitting },
  } = useForm<CreateFormData>({
    resolver: zodResolver(createFormSchema),
    defaultValues: { questionCount: 5, difficultyLevel: 'Medium', includeCorrectAnswers: true },
  });

  async function onSubmit(data: CreateFormData) {
    setServerError(null);
    try {
      const result = await generateForm(data);
      navigate(`/forms/${result.formId}/edit`);
    } catch (err: unknown) {
      const e = err as CustomResponse;
      setServerError(e.response?.data?.message ?? "Failed to generate form. Please try again.");
    }
  }

  return (
    <div className="min-h-screen bg-gray-50 flex items-center justify-center px-4 py-8">
      <div className="w-full max-w-lg bg-white rounded-2xl shadow-md p-8">
        <div className="mb-6">
          <h1 className="text-xl font-semibold text-gray-900">Create a new form</h1>
          <p className="text-sm text-gray-500 mt-1">
            Paste the content you want to turn into questions, and the AI will
            generate a draft form for you to edit.
          </p>
        </div>

        <form onSubmit={handleSubmit(onSubmit)} noValidate className="flex flex-col gap-4">
          <div className="flex flex-col gap-1">
            <label htmlFor="sourceText" className="text-sm font-medium text-gray-700">
              Source content
            </label>
            <textarea
              id="sourceText"
              rows={8}
              className={
                'w-full rounded-lg border px-3 py-2 text-sm shadow-sm outline-none ' +
                'focus:ring-2 focus:ring-brand-500 focus:border-brand-500 ' +
                (errors.sourceText ? 'border-red-400 focus:ring-red-400 ' : 'border-gray-300 ')
              }
              placeholder="Paste an article, study notes, or any text you want questions generated from…"
              {...register('sourceText')}
            />
            {errors.sourceText && (
              <span className="text-xs text-red-500">{errors.sourceText.message}</span>
            )}
          </div>

          <div className="grid grid-cols-2 gap-4">
            <div className="flex flex-col gap-1">
              <label htmlFor="questionCount" className="text-sm font-medium text-gray-700">
                Number of questions
              </label>
              <input
                id="questionCount"
                type="number"
                min={1}
                max={20}
                className={
                  'w-full rounded-lg border px-3 py-2 text-sm shadow-sm outline-none ' +
                  'focus:ring-2 focus:ring-brand-500 focus:border-brand-500 ' +
                  (errors.questionCount ? 'border-red-400 focus:ring-red-400 ' : 'border-gray-300 ')
                }
                {...register('questionCount')}
              />
              {errors.questionCount && (
                <span className="text-xs text-red-500">{errors.questionCount.message}</span>
              )}
            </div>

            <div className="flex flex-col gap-1">
              <label htmlFor="difficultyLevel" className="text-sm font-medium text-gray-700">
                Difficulty
              </label>
              <select
                id="difficultyLevel"
                className="w-full rounded-lg border border-gray-300 px-3 py-2 text-sm shadow-sm outline-none
                  focus:ring-2 focus:ring-brand-500 focus:border-brand-500"
                {...register('difficultyLevel')}
              >
                <option value="Easy">Easy</option>
                <option value="Medium">Medium</option>
                <option value="Hard">Hard</option>
              </select>
            </div>
          </div>

          <label className="flex items-center gap-2 text-sm text-gray-700">
            <input
              type="checkbox"
              className="rounded border-gray-300 text-brand-600 focus:ring-brand-500"
              {...register('includeCorrectAnswers')}
            />
            Include correct answers (for graded forms)
          </label>

          {serverError && (
            <div className="rounded-lg bg-red-50 border border-red-200 px-4 py-3 text-sm text-red-700">
              {serverError}
            </div>
          )}

          <div className="flex items-center justify-between mt-2">
            <Link to="/dashboard" className="text-sm text-gray-500 hover:underline">
              Cancel
            </Link>
            <Button type="submit" isLoading={isSubmitting}>
              Generate form
            </Button>
          </div>
        </form>
      </div>
    </div>
  );
}
```

Notes:
- Follows the exact `react-hook-form` + `zodResolver` + `CustomResponse` error-handling pattern already used in `RegisterPage.tsx` (same `err as CustomResponse` cast, same `e.response?.data?.message` fallback), so error handling behaves consistently across the app.
- `textarea`/`select`/checkbox are styled inline (matching `Input.tsx`'s classes) rather than reusing the `Input` component, since `Input` wraps a plain `<input>` only.
- `questionCount` uses `z.coerce.number()` so the string value React Hook Form reads off the number input is coerced before validation — no `valueAsNumber` wiring needed.
- On success, navigates straight into `FormEditorPage` (`/forms/:id/edit`) so the user lands on their new draft immediately, same as the plan's intended "click to edit" flow.

```csharp
namespace FormAI.Application.Forms.GetForm;

public record GetFormSummaryResponse(
    Guid Id,
    string Title,
    bool IsPublic,
    DateTime? ExpiresAt,
    DateTime CreatedAt,
    int SubmissionCount
);
```

**`src/FormAI.Application/Forms/GetForm/GetFormsByUserHandler.cs`** — pass the count through:

```csharp
public async Task<List<GetFormSummaryResponse>> HandleAsync(Guid requestingUserId, CancellationToken cancellationToken)
{
    var forms = await _formRepository.GetAllByUserIdAsync(requestingUserId, cancellationToken);
    return forms.Select(f =>
        new GetFormSummaryResponse(f.Id, f.Title, f.IsPublic, f.ExpiresAt, f.CreatedAt, f.Submissions.Count)).ToList();
}
```

**`src/FormAI.Infrastructure/Repositories/FormRepository.cs`** — load `Submissions` so
`f.Submissions.Count` isn't empty (EF Core navigation collections are empty by
default unless included):

```csharp
public async Task<IEnumerable<Form>> GetAllByUserIdAsync(Guid userId, CancellationToken cancellationToken = default)
{
    return await _context.Forms
            .Include(a => a.Submissions)
            .Where(a => a.CreatedBy == userId)
            .OrderByDescending(a => a.CreatedAt).ToListAsync(cancellationToken);
}
```

No migration needed — `SubmissionCount` is computed from the existing
`Submissions` navigation, not a new column. No route/controller change needed —
`GET /api/forms` already returns `GetFormSummaryResponse[]`.

### B3. New `frontend/src/components/SubmissionsPerFormChart.tsx`

```tsx
import type { FormSummary } from "../types/form";

type SubmissionsPerFormChartProps = {
  forms: FormSummary[];
};

export function SubmissionsPerFormChart({ forms }: Readonly<SubmissionsPerFormChartProps>) {
  if (forms.length === 0) return null;

  const sorted = [...forms].sort((a, b) => b.submissionCount - a.submissionCount);
  const max = Math.max(1, ...sorted.map(f => f.submissionCount));

  return (
    <section className="bg-white rounded-2xl shadow-md p-6">
      <h2 className="text-lg font-semibold text-gray-900 mb-4">Submissions per form</h2>
      <ul className="flex flex-col gap-3">
        {sorted.map(form => (
          <li
            key={form.id}
            className="flex items-center gap-3"
            title={`${form.title}: ${form.submissionCount} submission${form.submissionCount !== 1 ? 's' : ''}`}
          >
            <span className="w-32 shrink-0 truncate text-sm text-gray-600">
              {form.title}
            </span>
            <div className="flex-1 h-2.5 rounded-full bg-gray-100">
              <div
                className="h-2.5 rounded-full bg-brand-600"
                style={{ width: `${(form.submissionCount / max) * 100}%` }}
              />
            </div>
            <span className="w-8 shrink-0 text-right text-sm font-medium text-gray-900">
              {form.submissionCount}
            </span>
          </li>
        ))}
      </ul>
    </section>
  );
}
```

Design notes (per the dataviz process this project follows for charts):
- **Form**: this is a single series (submission count) compared across
  categories (forms) — a bar chart is the right pick, and since there's only one
  series, color encodes nothing extra, so every bar uses the same hue
  (`bg-brand-600`, the app's existing base brand color from `index.css`).
  No legend is needed for a single series — the chart title already names it.
- **Sort order**: descending by `submissionCount`, so the top of the list is the
  most-answered form and the bottom is the least-answered — both extremes are
  visible without scrolling or a second chart.
- **Marks**: thin bars (`h-2.5` = 10px), fully rounded ends, a light gray track
  (`bg-gray-100`) behind each bar as a baseline reference, and a direct numeric
  label at the end instead of relying on bar length alone.
- **Hover/accessibility**: a native `title` attribute gives an exact tooltip
  ("Form X: 12 submissions") on hover without any extra JS/library; labels are
  always visible as text, not color-only.
- **Empty state**: renders nothing (`null`) when the user has no forms yet, so
  it doesn't show an empty chart above the "no forms yet" message.

### B4. `frontend/src/pages/DashboardPage.tsx` — full updated file

This builds on the Phase 7 version (adds the "New form" button from Part A and
the chart from Part B):

```tsx
import { useEffect, useState } from "react";
import { useNavigate } from "react-router-dom";
import type { FormSummary } from "../types/form";
import { listForms } from "../api/forms";
import { Button } from "../components/Button";
import { FormCard } from "../components/FormCard";
import { SubmissionsPerFormChart } from "../components/SubmissionsPerFormChart";
import { useAuth } from "../context/useAuth";

type PageState = 'loading' | 'ready' | 'error';

export function DashboardPage() {
  const { user, logout } = useAuth();
  const navigate = useNavigate();

  const [state, setState] = useState<PageState>('loading');
  const [forms, setForms] = useState<FormSummary[]>([]);

  useEffect(() => {
    listForms().then(data => {
      setForms(data);
      setState('ready');
    }).catch(() => setState('error'));
  }, []);

  return (
    <div className="min-h-screen bg-gray-50">
      <header className="border-b border-gray-200 bg-white px-6 py-4 shadow-sm flex items-center justify-between">
        <h1 className="text-xl font-bold text-gray-900">Welcome, {user?.name ?? 'User'}!</h1>
        <div className="flex items-center gap-3">
          <Button onClick={() => navigate('/forms/new')}>New form</Button>
          <Button variant="outline" onClick={logout}>Log out</Button>
        </div>
      </header>

      <main className="mx-auto max-w-4xl px-4 py-8 flex flex-col gap-8">
        {state === 'ready' && <SubmissionsPerFormChart forms={forms} />}

        <div>
          <h2 className="text-lg font-semibold text-gray-900 mb-4">My forms</h2>

          {state === 'loading' && (
            <p className="text-gray-500">Loading your forms…</p>
          )}

          {state === 'error' && (
            <p className="text-red-600">Couldn't load your forms. Please try again later.</p>
          )}

          {state === 'ready' && forms.length === 0 && (
            <div className="py-16 text-center text-gray-400">
              <p className="text-lg">You haven't created any forms yet.</p>
            </div>
          )}

          {state === 'ready' && forms.length > 0 && (
            <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4">
              {forms.map(form => (
                <FormCard
                  key={form.id}
                  form={form}
                  onClick={() => navigate(`/forms/${form.id}/edit`)}
                />
              ))}
            </div>
          )}
        </div>
      </main>
    </div>
  );
}
```

The chart and the forms list both read from the same `forms` state — one
`listForms()` call on mount serves both, no extra request added.
